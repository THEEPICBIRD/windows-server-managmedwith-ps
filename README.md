# windows-server-managmedwith-ps
This repo contains scripts to perfom diffrent managment services on your AD server.

Remotemaintnace.ps1 is used to update services on your server and create a scheduled task to do this once ecery week.

changeouandusers.ps1 will create two new security groups and some spesific users to those groups.

createusers4.ps1 will create a unlimited number of users based of the information in your csv file.

usermapping.ps1 will create a report (csv file) of all users in your ad.

Get DHCP leases.ps1 will get all current DHCP leases on the spesified DHCP and give you a report.
